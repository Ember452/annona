# MySQL 索引笔记

## B+ 树与树高

InnoDB 页大小 16KB，非叶子节点只存键与指针，叶子节点存整行数据；三层 B+ 树约可承载两千万行。
树每加深一层，一次点查就多一次页访问，因此三层以内是常见的容量设计余量。

## 聚簇索引与二级索引

聚簇索引的叶子就是数据本身，二级索引的叶子存主键值，用二级索引定位到主键后还要回表。
覆盖索引指查询所需列全部落在索引里，免掉回表，是联合索引最典型的收益来源。

## 最左前缀

联合索引 (a, b, c) 只能从最左列开始连续匹配；跳过 a 直接查 b 用不上该索引的定位能力。
范围条件之后的列停止参与索引定位，只能作为覆盖数据被读取。
