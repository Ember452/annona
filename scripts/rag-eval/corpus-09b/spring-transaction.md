# Spring 事务

## 代理与自调用

事务由代理对象生效，方法内部 `this.other()` 的自调用绕过代理，注解完全不生效。
同类拆分、注入自身代理或改用 AspectJ 织入是三种常见绕法，各自的可测性代价不同。

## 传播行为

REQUIRED 有事务就加入、没有就新建；REQUIRES_NEW 总是挂起当前事务另开一个。
NESTED 在同一连接上保存点回滚，内层失败不必然导致外层回滚。

## 隔离与回滚

默认沿用数据库隔离级别，READ_COMMITTED 下仍可能遇到幻读，取决于存储引擎。
运行时异常默认回滚，受检异常默认不回滚，除非显式声明 rollbackFor。
只读事务的作用是让驱动与数据库做优化，不等于禁止写。
