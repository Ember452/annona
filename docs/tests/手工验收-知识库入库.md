# 手工验收 · 知识库入库（P1a-05 批 1 收口）

> 定位：CI 的 `KnowledgeIngestFlowIT`（真实 PG+Redis）已经用 **Fake** 存储/embedding
> 验证了管线的机械正确性（状态机、事务、分块落库、删除级联）；本教程用**真实文件 +
> 真实 embedding 模型**补上 CI 替代不了的两件事——Tika 对真实 PDF/DOCX 的中文提取
> 质量、真模型向量真的入库。两关都过，批 1（P1a-06 + P1a-05）才算验收闭合。
>
> 执行环境：需要 Docker Desktop（compose 栈）和一个 OpenAI 兼容 embedding API Key。

## 1. 前置准备

1. 确认 Docker Desktop 在运行，仓库已拉到待验收的 commit。
2. 复制 `.env.example` 为 `.env`，至少确认/修改以下项：

```ini
# —— 会话与数据库（compose 必需）——
ANNONA_SECRET_KEY=<openssl rand -base64 32 生成>
SPRING_DATASOURCE_PASSWORD=<自定一个密码>

# —— 对象存储（compose 内置 storage 容器，桶由应用自动创建）——
S3_ENABLED=true
S3_ENDPOINT=http://storage:9000
S3_BUCKET=annona
S3_ACCESS_KEY=<自定，如 annona-dev-ak>
S3_SECRET_KEY=<自定，≥8 位>

# —— embedding 模型（批 1 验收的关键项）——
ANNONA_MODEL_EMBEDDING_PROVIDER=openai-compatible
ANNONA_EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
ANNONA_EMBEDDING_API_KEY=<你的 Key>
ANNONA_DEFAULT_EMBEDDING_MODEL=text-embedding-v3
ANNONA_EMBEDDING_DIMENSIONS=1024
```

> 维度必须 1024（V4 向量列冻结值）；用 OpenAI 官方 `text-embedding-3-small`（1536 维）
> 等其他维度模型会报 2311 维度不一致——换维度属于新迁移，当前版本不支持。

3. 准备验收文件：一个**文字型 PDF**（扫描/图片型 PDF 提不出文本，属预期失败），
   一个 **DOCX**，一个 **MD**；各含中文标题与多段正文。

## 2. 启动

```bash
docker compose --env-file .env -f docker/docker-compose.yml up -d --wait
docker compose -f docker/docker-compose.yml ps        # 5 个服务应全部 healthy
```

打开 <http://localhost/> → 注册并登录（local 模式）→ 侧边栏「知识库」。

## 3. 验收用例

| # | 操作 | 预期 |
|---|---|---|
| A | 选方向 → 上传**真实 PDF** → 观察进度 | 进度依次：解析中 → 分块中 → 向量化中（带 n/total 计数）→ 状态徽标「就绪」 |
| B | 上传**真实 DOCX** | 同上 |
| C | 对 A/B 点「分块预览」 | 能看到分块列表：标题路径（如"第一章 > 小节"）、偏移区间、中文内容**无乱码**、块边界落在句子附近而非词中间 |
| D | **重复上传同一文件** | 秒级返回"已在库中，本次未产生任何解析与向量消耗"，列表不出现第二行 |
| E | 点「删除」并确认 | 列表行消失；`docker compose exec storage ls /data` 侧观察不强制，以页面为准 |

每一步的失败都会落在文档行的「失败」徽标 + 可读原因上——把原因原文记下来对照 §4。

## 4. 常见失败与排查

| FAILED 原因 | 根因 | 处置 |
|---|---|---|
| 向量化失败 / embedding 服务返回 HTTP 401 | Key 无效或 Base URL 错 | 核对 `ANNONA_EMBEDDING_API_KEY` / `BASE_URL`，重启栈 |
| embedding 维度 … 与配置 1024 不一致 | 模型维度不是 1024 | 换 1024 维模型（如 text-embedding-v3） |
| 解析失败 | 加密 PDF / 损坏文件 | 换正常文件；属预期边界 |
| 解析后没有可用文本 | 扫描件（图片型 PDF） | 预期行为，v1 不做 OCR |
| 对象存储未配置 | `S3_ENABLED` 未设 true | 设 true 后重启栈 |
| 进度长时间卡在向量化中 | 网络/限流导致重试中（最多 3 次） | `docker compose logs server \| grep -i embed` 观察 |
