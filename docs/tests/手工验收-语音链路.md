# 手工验收：语音链路（P3 批 1，DashScope 真 Key 冒烟）

- 适用：P3 批 1（/ws/voice 全链路骨架 + 流式 ASR + 开场白 TTS）。批 2 的对话追问/评估、批 3 的延迟实测不在此教程范围。
- 前置：**Windows 本机应用 + 中间件跑 VM dev 栈**（同 P1a-09 检索基线的部署口径），DashScope API Key 一个（ASR/TTS 同 Key 可共用，DashScope 场景）。

## 1. 环境准备

`.env`（模板 `.env.example`）新增语音段：

```text
ANNONA_MODEL_ASR_PROVIDER=dashscope
ANNONA_ASR_URL=wss://dashscope.aliyuncs.com/api-ws/v1/realtime
ANNONA_ASR_API_KEY=<你的 DashScope Key>
ANNONA_DEFAULT_ASR_MODEL=qwen3-asr-flash-realtime

ANNONA_MODEL_TTS_PROVIDER=dashscope
ANNONA_TTS_URL=wss://dashscope.aliyuncs.com/api-ws/v1/realtime
ANNONA_TTS_API_KEY=<同一个 Key 即可>
ANNONA_DEFAULT_TTS_MODEL=qwen3-tts-flash-realtime
ANNONA_TTS_VOICE=Cherry
```

冒烟最小化：chat/embedding 可保持 none（批 1 语音链路不依赖 LLM）。

## 2. 启动与冒烟步骤

```powershell
.\mvnw.cmd -q -DskipTests package -pl annona-server -am
java -jar annona-server\target\annona-server.jar
cd annona-web; pnpm build   # 产物进 annona-server static/；或 pnpm dev 直连
```

浏览器（Chrome/Edge，需 AudioWorklet）：

1. 登录后进入 `模拟面试` → 点「试试语音面试（内测）」（或直达 `/interview/voice`）。
2. 点「开始会话」。**预期**：状态变 ACTIVE · 识别就绪；扬声器播放开场白（fake/真 TTS 均有音频，DashScope 应为人声）；字幕区出现"面试官：<开场白>"。
3. 授权麦克风（第一次点麦克风按钮），对着麦克风说一句话，停顿约半秒（server_vad 400ms 静音断句）。**预期**：说话过程中字幕区出现灰色草稿（partial，实时变化）；停顿后草稿变白底定稿行（final）。
4. 在下方输入框手打一句提交。**预期**：同样进入定稿流（手动与语音同一落库通道）。
5. 点「结束会话」。**预期**：状态变 FINALIZED，连接关闭。

## 3. 落库核验（psql / 任意客户端）

```sql
select status, asr_model, tts_model,
       left(transcript, 120) as transcript_head,
       finalized_at
from voice_session order by created_at desc limit 3;
```

预期：FINALIZED、asr_model=qwen3-asr-flash-realtime、tts_model=qwen3-tts-flash-realtime、
transcript 含你说的句子（**不应有任何音频二进制**——voice-adr 隐私红线）。

## 4. 已知的协议校准点（本批直连无 SDK，ADR §否决的备选）

DashScope Omni realtime 的 `session.update` 内字段形状以官方文档为准。若 ASR 一直无
partial（浏览器侧已在说话、网络面板里 WS 帧在动），按顺序查：

1. 握手：WS URL 为 `wss://…/api-ws/v1/realtime?model=<model>`，`Authorization: Bearer <key>`——401/403 说明 Key 或 URL 错；
2. `input_audio_format`：本批默认 `pcm,16000`，若服务端报格式错，改 `.env` 的
   `ANNONA_ASR_INPUT_FORMAT`（如 `pcm` 或 `pcm_s16le`，以官方文档为准），**不用重编译**；
3. TTS：若开场白只出字幕不出声音且日志见 `[voice-tts]` error 事件，同理检查
   `response_format`（`pcm,24000`）与 voice 名（`Cherry` 为 DashScope 官方音色）。

任何一步的报错帧（`{"type":"error",...}`）会原样透传到页面红色错误条，把 message 抄下来对照 DashScope 文档即可定位。
