# 决策 A/B 基线 — 决策选题 vs 随机选题

- 日期：2026-10-01（协议定稿）/ 状态：⚠️ **数字待部署实跑**（本机无 Docker/PG，见 AGENTS §0.9 与规则 8）
- 脚本：[scripts/ab-decision/ab.py](../scripts/ab-decision/ab.py) ·依据：设计文档 §6.5、planner-decision-kernel-adr

## 实验设计（固定协议，可复现）

同一 demo 用户 + 同一题库（`DemoSeedRunner` 灌 6 周历史），各跑 N=8 场、每场 5 题：

| 组 | planMode | 选题来源 |
|---|---|---|
| decision | auto | planner 规则链（FORGETTING_CURVE/WEAK_DIRECTION）+ 复习题掺入 |
| random | manual | 请求均匀难度基线（不经决策） |

度量：① decision 组 `REMIND_REVIEW` 命中数（复习题是否真的被前置）；② 两组选题的难度分布；
③ 固定考生模型下"弱项被复现的频率"（decision 应更高，因为它盯着低分方向）。

## 实跑步骤

1. 部署实例加 `--annona.demo.enabled=true` 启动（compose 或 `java -jar ... --annona.demo.enabled=true`）。
2. demo 账号（`demo@annona.test`）登录取会话 token。
3. `python scripts/ab-decision/ab.py --direction <demo方向id> --sessions 8`
4. 把脚本输出的两组统计填进下表，结论写"决策是否优于随机"；不优则按维护规则 5 公开写进 README。
