## 2. 本阶段产出的能力（用户视角）

- 面试不再是"练 100 场和 1 场拿同一套题"：低分方向被加压、久不练方向掺复习题。
- 每场面试可回答"凭什么这么考我"：规则链每条命中/保护都留痕，面板逐条人话展示，含数据质量等级与"数据不足/仅面试表现"状态。
- 用户能反驳：点"这条不对"累计 3 次自动停用该规则，后续决策不再受其影响——决策是双向的。
- 学习信号按方向隔离：背政治不进 Java 面试决策（相交才增强，方向不相交是正常形态）。

## 4. 与原设计的偏离（已回写文档）

- **mastery 不建物化表**：现算纯函数（planner-decision-kernel-adr 决策 3）；设计文档 §5.3 表清单的 `mastery` 行标注为"不落表，现算"。
- **plan_task/todo_item 不存在**：P1c-07"反哺 todo"改为 `REMIND_REVIEW` trace；真回写待 P2-06 建表（ADR 记录）。
- **completionPercent 恒 null**：数据源（plan_task）P2-06 才建；SPI 契约保留字段但文档化 null 语义。
- **SignalSnapshot 加方向维度（修订 4）**：direction ADR 修订 3 遗留义务履行；PlannedQuestion.directionKey→directionId（收修订 2）。
- **CAP_RATIO 重定位**：单方向会话下"单方向≤40%"不 bind（用户自选方向），改为复习题占比上限 reviewRatio 治理（§6.4 保护 3 的现实形态），多方向自动配额待 planner 跨方向选题落地再评估。
