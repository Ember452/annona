## 2. 本阶段产出的能力（用户视角）

站在下一个新人 clone 仓库的视角，P0 完成后**能做的事**：

1. **本地零依赖跑起来看代码对不对**：`.\mvnw.cmd -B -q verify` 全绿（34 单测 + 7 ArchUnit 规则 + 5 Fake smoke = 39 tests，`mvn -B -q verify EXIT=0` 已在 B5 HEAD 复验）。不需要本机装 Docker / PG / Redis。
2. **一条命令拉起完整栈**（Linux/macOS 或 Windows Git Bash）：`make quickstart` → compose 起 5 服务 → Flyway 自动迁移 → 打印访问地址。Windows PowerShell 用户走 `docker compose -f docker/docker-compose.yml --env-file .env up -d --wait`。
3. **前端能构建，产物注入 server**：`cd annona-web; pnpm install; pnpm build` → `annona-server/src/main/resources/static/index.html` 生成，浏览器打开 `localhost:8080` 见首页。
4. **一次健康探针**：`curl localhost:8080/api/meta/ping` 返回 `{"code":0,"message":"ok","data":"pong","traceId":"..."}`；这是 `Result<T>` / `ErrorCode` / 全局异常处理器的最小可视证据。
5. **PR 会被机器拦**：中文 subject 的 commit 会被 `.githooks/commit-msg` 拒；文件里塞 `ghp_...` 会被 `.githooks/pre-commit` 的 gitleaks 拒；`modules/*` 里 import `infrastructure/*` 会被 ArchUnit 7 拒；跨模块 Spring 依赖会被 enforcer 与 ArchUnit 双拒。
6. **CI 会真的跑一遍**：`ci.yml` 5 个 blocking job（unit / docker-it / compose-smoke / frontend / gitleaks）在每次 PR 触发；集测用 `services:` 起 `pgvector/pgvector:pg16` + `redis:7-alpine`（本机不跑，CI 跑，见 dockerless ADR）。
7. **扩展点有骨架 + 内存实现**：五个 SPI（`IdentityProvider` / `ModelProvider` / `Retriever` / `LearningSignalReader` / `DecisionRule`）都有可 `new` 的 Fake；P1a 起业务模块写 `@MockBean` 时不用从零造。

**这些是"用户视角能做什么"，不是类清单**（AGENTS.md §7 §2）。

## 4. 与原设计的偏离（已回写主文档）

| 偏离点 | 原设计（结构文档 / ADR） | 实际落地 | 回写位置 |
|---|---|---|---|
| Boot 4 starter 名称 | 沿用 Boot 3 直觉写 `spring-boot-starter-web` / `spring-boot-starter-data-jpa` 等 | Boot 4 拆包：`spring-boot-starter-webmvc`、`spring-boot-starter-flyway`、`spring-boot-starter-validation` 等；autoconfig FQN 也搬到 `org.springframework.boot.jdbc.autoconfigure.DataSourceAutoConfiguration` 类新路径 | 借鉴地图 §A "P0-05 依赖名修正（已实测）"行（B2） |
| Jackson 双 BOM | 单一 `jackson-bom.version` | Boot 4 分家：`jackson-bom.version`（Jackson 3）+ `jackson-2-bom.version`（fasterxml 兼容）；本项目 Jackson 3 尚未成熟，实际用 Jackson 2 BOM bump 到 `2.22.1` 保持 `com.fasterxml.jackson.*` import 不断 | 根 `pom.xml` properties 注释 |
| Surefire `*IT.java` include | 只依赖 Boot 4 默认 | Boot 4 默认 surefire 3.x 仍不 include `*IT.java` 除非显式；补 `<include>**/*IT.java</include>` 与 `<excludedGroups>docker</excludedGroups>` | 根 pom `pluginManagement`（B2） |
| `MetaController` 包路径 | 结构 §4 未明写运维探针归属 | 移到 `io.annona.shared.meta`（不是 `io.annona.web`），避免 `shared/` 与 `config/web/` 职责混淆 | 结构文档 §4 已在 B2 doc-sync 中显式加 `shared/meta/` 子包（`063a45a`） |
| Docker 服务命名 | 直觉按技术命名 `postgres` / `redis` / `minio` | 按角色命名 `db` / `cache` / `storage` / `server` / `web`；`container_name` 加 `annona-` 前缀避全局冲突 | B4 `docker/docker-compose.yml` |
| pgvector 镜像 tag | `postgres:16` + 手工装扩展 | 直接 `pgvector/pgvector:pg16`（官方镜像，扩展预装）；`docker/postgres/init.sql` 只做 `CREATE EXTENSION`，不建表（表归 Flyway V1） | B4 `docker-compose.yml` + B2 `V1__baseline.sql` 双头 |
| `mvnw` exec bit 丢失 | Windows `core.filemode=false` 使 commit 时权限位不写进 tree | `git update-index --chmod=+x mvnw` 强制记入 tree；CI 每个 Java job 保留 `chmod +x mvnw` step 双保险 | B5 commit 2 `e7d3e6f`（ci.yml 与 mvnw 同批） |
| `pnpm-workspace.yaml` allowBuilds | Vite 官方模板不写 | pnpm 11 强制 `onlyBuiltDependencies` 白名单；补 `esbuild` 与 `unrs-resolver` 两条 | B3 `annona-web/pnpm-workspace.yaml`（`a0de081`） |
| commit-msg hook 语义 | 🅖 的 hook 要求"标题必须含中文" | **反向**：AGENTS.md §5 规定 annona commit message 一律英文；hook 用 perl `\p{Han}` 检测**禁**汉字；不强制 `- ` bullet body（🅖 强制） | B5 commit 1 `66fdc3e` |
| ArchUnit 白名单机制 | 计划里说"故意违规 import 能红"就够了 | 实际加 `resources/archunit-whitelist.properties`（当前空）；未来 P1 迁移期开红名单，规则的 `allowEmptyShould` 兜住无匹配类的假通过 | B1 `c78eee3` |

## 5. 已知缺陷与技术债

| # | 缺陷 / 债务 | 影响 | 触发处理的条件 | 归属 |
