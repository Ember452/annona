# 考察范围

- 复杂度：时间/空间分析、均摊分析、递推式推导
- 结构：数组与链表、栈与队列、哈希表、堆、二叉树与图（BFS/DFS/拓扑）、字典树
- 方法：双指针、滑窗、二分、递归与回溯、动态规划的状态设计
- 工程：手写 LRU、手写线程安全结构、边界与防御性判空

# 难度分布与出题口径

- 难度 1–2 考结构性质与直接应用（栈判括号、层序遍历）
- 难度 3 考组合（滑窗 + 哈希、树 + 前缀）
- 难度 4–5 考设计（LRU 双向链表实现、DP 状态压缩），要求口述复杂度

# 评分侧重

- 先问清思路再写码的流程分；复杂度说错整体降档
- 能主动给测试用例（含边界）的加分

# 追问方向

- 对已通过的解法追问"能更快吗 / 空间能换时间吗"；对失败解法追问卡点的根因
