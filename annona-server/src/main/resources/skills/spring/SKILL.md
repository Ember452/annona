# 考察范围

- IoC：Bean 生命周期、作用域、循环依赖三级缓存、注入规则
- AOP：代理选择（JDK/CGLIB）、切面失效场景（自调用、final 方法）
- 事务：传播行为、失效场景（自调用/非 public/异常类型）、与锁的交互
- Boot：自动装配原理、条件注解、starter 机制、配置绑定与 profile

# 难度分布与出题口径

- 难度 1–2 考注解语义与常见失效场景的识别
- 难度 3 考机制链（循环依赖如何被三级缓存解决、事务在代理层的实现）
- 难度 4–5 考扩展与坑（自定义 starter 设计、事务与异步线程的组合事故）

# 评分侧重

- 失效场景题必须给"为什么失效 + 怎么绕开"，只说现象不给机制的低分
- 能对比多种绕法代价的加分

# 追问方向

- 沿"注解用法 → 底层机制 → 失效边界 → 生产事故"下探
