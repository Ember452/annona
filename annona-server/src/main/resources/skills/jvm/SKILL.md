# 考察范围

- 内存区域：堆分代、元空间、栈帧、直接内存；对象分配（TLAB、逃逸分析）
- 垃圾回收：可达性分析、各收集器（CMS/G1/ZGC）的取舍、晋升与担保失败
- 类加载：双亲委派、打破场景、热部署边界
- 诊断：jstat/jmap/jstack/jfr 的分工、OOM 类型判别、GC 日志解读

# 难度分布与出题口径

- 难度 1–2 考结构（哪些区域会 OOM、各区域存放什么）
- 难度 3 考机制（G1 的 Region 与停顿目标如何达成、Full GC 触发链）
- 难度 4–5 考调优案例（给定 GC 日志判断瓶颈、元空间泄漏排查）

# 评分侧重

- 调优题必须给"现象 → 假设 → 验证 → 结论"的完整链路，只有参数建议不给依据的低分
- 能说出各收集器适用边界的加分

# 追问方向

- 从现象追到日志证据，再追到参数含义；案例题追问"调了没效果怎么办"
