# 考察范围

- 传输层：TCP 三次握手/四次挥手与状态机、滑动窗口与拥塞控制、TIME_WAIT 治理
- 应用层：HTTP/1.1 与 2 的分界（队头阻塞、多路复用）、TLS 握手、长连接管理
- 操作系统：进程线程调度、虚拟内存与缺页、IO 多路复用（select/poll/epoll）
- 实战：抓包定位、连接数异常排查、文件句柄泄漏

# 难度分布与出题口径

- 难度 1–2 考协议语义（握手为什么是三次、304 与强缓存的分工）
- 难度 3 考机制（epoll 的就绪队列、拥塞控制的阶段转换）
- 难度 4–5 考诊断（线上大量 TIME_WAIT 的定位与处置、CPU 突刺的系统级排查）

# 评分侧重

- 协议题要求画得出状态转换，只背口诀的低分
- 诊断题按"工具 → 证据 → 结论"给分

# 追问方向

- 从协议行为追到内核机制，再追到线上现象；诊断题追问下一步验证手段
