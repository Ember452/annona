# 考察范围

- 数据结构：五大数据结构的底层实现（SDS、跳表、压缩列表/列表包）、适用场景与编码切换
- 持久化：RDB 与 AOF 的取舍、混合持久化、重写机制
- 缓存模式：穿透/击穿/雪崩的成因与对策、一致性方案（先删后写 vs 延迟双删）、热点 key
- 高可用：主从复制原理、哨兵切换、Cluster 分片与重定向

# 难度分布与出题口径

- 难度 1–2 考用法（数据结构选型、过期策略）
- 难度 3 考机制（复制积压缓冲区、AOF 重写期间的写处理）
- 难度 4–5 考方案设计（缓存与 DB 一致性方案对比、大集群热分片的治理）

# 评分侧重

- 方案题要求给"代价 + 适用边界"，只报"加缓存"三字的低分
- 能用量化数字（命中率、延迟预算）支撑决策的加分

# 追问方向

- 从用法追到底层实现，再追到故障场景；方案题追问"流量再大十倍怎么办"
