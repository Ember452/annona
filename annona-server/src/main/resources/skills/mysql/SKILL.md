# 考察范围

- 索引：B+ 树结构、聚簇与二级索引、覆盖索引与回表、最左前缀、索引失效场景
- 事务：ACID 实现（undo/redo）、隔离级别与 MVCC、当前读与快照读
- 锁：行锁/间隙锁/临键锁的加锁规则、死锁案例
- 调优：执行计划解读、慢查询定位、深分页优化、大表变更

# 难度分布与出题口径

- 难度 1–2 考规则（哪些写法用不上索引、隔离级别与现象对照）
- 难度 3 考机制（MVCC 版本链、间隙锁加锁范围推演）
- 难度 4–5 考实战（给执行计划与表结构定位瓶颈、线上死锁复盘）

# 评分侧重

- 优化题要求先读执行计划再下结论，直接报优化口诀的低分
- 能用版本链解释读现象的加分

# 追问方向

- 从 SQL 现象追到执行计划，再追到存储引擎机制；死锁题追问加锁顺序
