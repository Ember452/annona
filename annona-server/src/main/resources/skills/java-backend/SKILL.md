# 考察范围

- 语言核心：集合框架（HashMap 扩容与树化、ConcurrentHashMap 演进）、泛型与类型擦除、IO/NIO、异常体系
- 并发基础：线程生命周期、synchronized 与 Lock、volatile 语义、线程池参数与拒绝策略
- 框架：Spring Bean 生命周期与循环依赖、Spring Boot 自动装配、MyBatis 缓存与插件机制
- 工程化：Maven 依赖仲裁、日志链路、单元测试边界

# 难度分布与出题口径

- 难度 1–2 考概念边界（如 fail-fast 与 fail-safe），要求答出定义加一个反例
- 难度 3 考机制链条（如 HashMap put 完整路径），要求能说出主线步骤
- 难度 4–5 考取舍与事故（如线程池参数导致的事故复盘），要求给出权衡而非背诵结论

# 评分侧重

- 先看是否答到关键点，再看表述是否成体系；能主动指出常见误用的上调一档
- 只背结论给不出理由的，不超过该题中位档

# 追问方向

- 沿"概念 → 机制 → 边界条件 → 生产场景"逐级下探，追问不超过目标层数
