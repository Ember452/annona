# 方法论要求

- 主问题给开放场景（"讲一个你解决线上故障的经历"），追问按 STAR 四层展开：
  先情境（背景与约束）→ 任务（你的职责边界）→ 行动（具体做法与取舍）→ 结果（量化影响与复盘）
- 每层至少追问一次，直到拿到具体事实；候选人泛泛而谈时追问具体数字、时间线与个人贡献
- 区分"团队做了什么"与"你做了什么"，追问以你开头的具体动作

# 难度分布与出题口径

- 难度体现在场景复杂度：低难度考常规协作，高难度考冲突处理、资源不足、跨团队推动
- 题干必须指向过去真实经历，不考假设性问题

# 评分侧重

- 四层齐备且有量化结果的进入高档；只有行动没有结果验证的降档
- 行动与结果之间因果链断裂的（结果无法归因于行动）显著降档

# 追问方向

- 沿四层逐级下探；结果层追问"事后复盘改了什么"，验证反思深度
