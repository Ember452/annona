# 方法论要求

- 按固定维度出题：每个维度一题，题量平均分配，不出偏题怪题
- 每题必须有明确的评分标准（关键点 + 分档描述），评分可复现
- 题目之间不共享线索：前一题的回答不影响后一题的提问内容

# 难度分布与出题口径

- 全卷难度均匀分布（1–5 各档都有），不因方向冷门而偏难
- 题干自包含：不依赖考生简历或前文上下文即可作答

# 评分侧重

- 按档给分：未达关键点下限即降档，不因表述流利虚高
- 追问只用于确认理解，不用于引导答案

# 追问方向

- 追问限于题干范围内的事实澄清（"你说的 X 具体指什么"），不做跨维扩展
